Natan-app v1.2.0 — archivos para copiar sobre el proyecto
==========================================================

Este zip contiene SOLO los archivos nuevos o modificados respecto a lo que hoy está en
GitHub (commit 441a0bc). No hay archivos borrados ni cambios en package.json, así que
no hace falta instalar nada.

Cómo aplicarlo
--------------
1. Extraé este zip DENTRO de la carpeta del proyecto (C:\Users\Jesus\Desktop\Projects\Natan-app),
   aceptando reemplazar los archivos existentes. Las carpetas src/ y data/ del zip se
   fusionan con las tuyas.
2. En Git Bash:
      npm run build          (debe terminar sin errores)
      git add -A
      git commit -m "v1.2.0: inventario, modo oscuro, datos del negocio, gráficos"
      git push

- data/inventory-hidden-creek-shop.xlsx / .csv   inventario transcrito (128 unidades, $17,265.90)
