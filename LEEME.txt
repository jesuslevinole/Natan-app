Natan-app V0045 — archivos para copiar sobre el proyecto
=========================================================
8 archivos sobre tu GitHub actual (V0044). Sin dependencias nuevas y sin
reglas de Firestore.

Cómo aplicarlo
--------------
1. Extraé el zip DENTRO de la carpeta del proyecto, reemplazando los existentes.
2. npm run build
3. git add -A && git commit -m "V0045" && git push

Qué trae V0045
--------------
1. CATÁLOGO CON MODELO Y SERIAL: en Catalogs → Item Names cada artículo ahora
   guarda también "Model / Part #" y "Serial #" (junto a la foto). Aparecen en
   el formulario y como columnas de la tabla. La importación de inventario
   también guarda el modelo cuando crea item names nuevos.
2. AUTOCOMPLETADO EN ITEM ENTRANCE: al elegir un producto del catálogo en
   "Search from Catalog", el Model / Part #, el Serial # y la Category se
   llenan solos con lo que tenga el catálogo. Igual podés corregirlos en la
   fila (por ejemplo el serial de la unidad concreta que llegó).
3. PO # ABIERTO: el campo ya no está bloqueado. Viene sugerido con el número
   automático de siempre (PO0024, PO0025...), pero podés escribir el que
   quieras (se guarda en mayúsculas). Si escribís un PO # que ya existe en
   otra entrada, sale un aviso naranja — no te bloquea, solo te avisa porque
   los reportes agrupan las filas por PO #.
La campana anuncia la V0045.
