Natan-app V0048 — archivos para copiar sobre el proyecto
=========================================================
5 archivos sobre tu GitHub actual (V0047). Sin dependencias nuevas y sin
reglas de Firestore.

Cómo aplicarlo
--------------
1. Extraé el zip DENTRO de la carpeta del proyecto, reemplazando los existentes.
2. npm run build
3. git add -A && git commit -m "V0048" && git push

Qué trae V0048 — ADD PRODUCT CON EL CATÁLOGO COMPLETO
------------------------------------------------------
1. Al presionar "Add Product" se abre un modal con LA TABLA DE TODOS LOS
   PRODUCTOS del catálogo: foto, nombre, categoría, Part / Union # y Model #,
   con un BUSCADOR arriba que filtra por nombre, categoría, part, model,
   serial o SKU mientras escribís.
2. Al seleccionar un producto (clic en la fila o en "Select"), pasás a una
   pantalla que ya trae precargado todo lo que el catálogo sabe (los 4
   identificadores + categoría) y solo te pregunta lo que falta: fecha de
   llegada, cantidad, precio, factura, garantía, fabricante y notas.
3. El botón "Add to this PO" agrega el producto a la tabla del PO y NO CIERRA
   el modal: te devuelve a la lista del catálogo con un aviso verde
   ("Bathroom Faucet was added to this PO (3 products)...") para que sigas
   agregando. Cuando termines, botón "Done".
4. "Not in catalog": para productos que no están en el catálogo, escribís el
   nombre a mano como siempre.
5. Editar un producto ya agregado (lápiz) abre la misma ventana con los datos
   cargados y el botón "Update Product".
La campana anuncia la V0048.
