Natan-app V0040 — archivos para copiar sobre el proyecto
=========================================================
13 archivos sobre tu GitHub actual (V0039). Sin dependencias nuevas y sin
reglas nuevas de Firestore.

Cómo aplicarlo
--------------
1. Extraé el zip DENTRO de la carpeta del proyecto, reemplazando los existentes.
2. npm run build
3. git add -A && git commit -m "V0040" && git push

Qué trae V0040 — MODO DE PRUEBA (view as)
-----------------------------------------
1. En Account Users cada fila tiene ahora un ícono de OJO: al tocarlo, ves la
   app EXACTAMENTE como ese usuario, con su rol completo (menú, permisos,
   botones y el Chat con su nombre y sus conversaciones).
2. Mientras estás en modo prueba, una BARRA NARANJA arriba te recuerda como
   quién estás viendo y con qué rol, con el botón "Exit test mode" para volver
   a ser vos. Recargar la página también te devuelve a tu sesión real.
3. Todo lo que hagas en modo prueba queda en Activity History como
   "Usuario (test by Jesus Molero)" — el historial nunca miente.
4. Permiso nuevo en Manage Roles → Account Users: "View the app as another
   user (test mode)". Por defecto lo heredan solo los roles de administración.
5. "Log Out" durante el modo prueba solo sale del modo (no cierra tu sesión).
La campana anuncia la V0040 con estas novedades.

Para probar el chat: entrá como un usuario (ojo), mandate un mensaje a vos
mismo (tu usuario real), salí del modo y vas a ver el mensaje sin leer en tu
propio Chat.
