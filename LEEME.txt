Natan-app V0046 — archivos para copiar sobre el proyecto
=========================================================
9 archivos sobre tu GitHub actual (V0045). Sin dependencias nuevas y sin
reglas de Firestore.

Cómo aplicarlo
--------------
1. Extraé el zip DENTRO de la carpeta del proyecto, reemplazando los existentes.
2. npm run build
3. git add -A && git commit -m "V0046" && git push

Qué trae V0046
--------------
1. CATÁLOGO CON LOS 4 IDENTIFICADORES: cada artículo de Item Names guarda ahora
   Part / Union #, Model #, Serial / MFG # y Store SKU / Internet # (además de
   la categoría y la foto). Lo que ya tenías guardado como Model y Serial se
   conserva tal cual.
2. ITEM ENTRANCE LOS JALA SOLOS: al elegir el producto en "Search from
   Catalog" se llenan automáticamente los 4 campos + la categoría. Part/Union
   y Store SKU tienen su propio campo en el formulario, y en la tabla de
   productos están como columnas opcionales (se activan desde "Columns" para
   no ensanchar la tabla de más). Todo sigue editable después de llenarse.
3. La plantilla de importación también acepta las columnas nuevas
   "Part / Union #" y "Store SKU / Internet #" (descargala de nuevo para ver
   los ejemplos), y los item names que crea la importación las guardan.
La campana anuncia la V0046.
