Natan-app V0039 — archivos para copiar sobre el proyecto
=========================================================
Archivos nuevos o modificados sobre tu GitHub actual (V0038). Sin dependencias
nuevas (no hace falta npm install).

Cómo aplicarlo
--------------
1. Extraé el zip DENTRO de la carpeta del proyecto, reemplazando los existentes.
2. npm run build
3. git add -A && git commit -m "V0039" && git push

IMPORTANTE — Firebase Console → Firestore → Reglas, agregar (sin esto el chat
no funciona):
      match /chats/{chatId} {
        allow read, write: if request.auth != null;
        match /messages/{msgId} {
          allow read, write: if request.auth != null;
        }
      }

Qué trae V0039
--------------
1. FOTO POR ARTÍCULO:
   - En Catalogs → Item Names cada artículo tiene ahora un campo Photo: subís
     una imagen (se redimensiona sola a 320px) y queda guardada con el registro.
   - La miniatura se ve en la tabla del catálogo Y junto a cada producto dentro
     de Item Entrance. Clic en la miniatura = se ve en grande.
2. CHAT INTERNO (ítem "Chat" en el menú, visible para todos los usuarios):
   - Mensajes directos entre dos usuarios o grupos con nombre y miembros.
   - En tiempo real, con punto azul de no leídos, separadores por día y hora
     en cada mensaje. En el teléfono funciona como WhatsApp (lista → chat).
   - En Manage Roles hay un permiso nuevo "Chat" por si querés limitarlo.
3. IMPORTACIÓN FÁCIL DE PRODUCTOS (Item Entrance → Import):
   - Botón "Download import template (.xlsx)": plantilla con una hoja Products
     (una fila por producto, con Qty, ejemplos incluidos) y una hoja
     Instructions que explica cada columna.
   - Las filas con el mismo PO # se agrupan en una sola entrada.
   - Si el Item Name o el Vendor no existen en los catálogos, se agregan solos.
La campana anuncia la V0039 con estas novedades.
