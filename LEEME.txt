Natan-app V0038 — archivos para copiar sobre el proyecto
=========================================================
10 archivos sobre tu GitHub actual (que está en V0036). Este zip incluye TAMBIÉN
los arreglos de la V0037 (scrollbars y modo oscuro) por si todavía no la subiste:
si ya la aplicaste, no pasa nada — son los mismos archivos y se pisan igual.
Sin dependencias nuevas y sin reglas nuevas de Firestore.

Cómo aplicarlo
--------------
1. Extraé el zip DENTRO de la carpeta del proyecto, reemplazando los existentes.
2. npm run build
3. git add -A && git commit -m "V0038" && git push

Qué trae V0038
--------------
1. FINISHED BY AUTOMÁTICO: al marcar Work Finish = YES ya no se puede elegir
   quién finalizó. El campo quedó de solo lectura "(recorded automatically)" y
   muestra al usuario logueado: quien marca YES es quien queda registrado, con
   la fecha. Si la orden ya estaba finalizada y otro la edita, se conserva el
   sello original; si se reabre (NO), se limpia y se vuelve a registrar al
   finalizarla de nuevo.

ambos temas y el modo oscuro con el menú lateral y los badges legibles.)
